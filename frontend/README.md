# Adaptive MCP-AI System - Frontend

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The app will be available at http://localhost:3000

## Features

- **MCP Request Console**: Send REST API requests to the backend
- **WebSocket Streaming**: Real-time streaming responses
- **Dashboard**: View routing logs and statistics

## Pages

- `/` - MCP Request Console
- `/streaming` - WebSocket Streaming Console
- `/dashboard` - Analytics Dashboard
